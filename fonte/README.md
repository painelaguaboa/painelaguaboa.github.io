# Fonte editável do Painel Destacamento Água Boa

Leia `LER_PRIMEIRO.md` para o passo a passo de gerar o `index.html`.

Esta pasta no repositório público traz só a linha de montagem do HTML (base, parts, patches, montar/build e o essencial de ferramentas). Não inclui o `Code.gs` nem o guia de implantação do servidor, porque esses arquivos têm IDs de planilhas internas e da pasta 07.

As fontes webfont (`.woff2`) e o `escudo.webp` ficam na pasta Fonte do Drive, em `ferramentas/`. Sem eles, o `build.py` procura os mesmos arquivos em caminhos locais já usados na box.

Versão oficial no ar: v4.3.5. A v4.3.6 de teste do HTML está em `/teste-v436/`.
